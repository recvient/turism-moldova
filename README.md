# Descoperă Moldova

Mini-site despre turismul în Republica Moldova, realizat la disciplina **Dezvoltarea paginilor Web**.

Autor: Starciuc Alexandra, grupa RC-25

## Structura proiectului

```
turism-moldova/
├── index.html      pagina principală (Acasă)
├── despre.html     obiective turistice, galerie, video
├── contact.html    formular de contact
├── 404.html        pagina afișată pentru adrese greșite
├── css/style.css   stilurile comune
├── img/            imagini
└── video/          videoclip
```
